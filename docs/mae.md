# 真絵（mae Native）

[公開仕様書](https://efasus.sakura.ne.jp/shiori_mae.html)から作った独立実装です。原作DLLの移植ではなく、バージョン0.1.0の部分互換版です。

ZIP内の`mae/lib/libmae.dylib`をゴーストの`ghost/master/`へ置き、`descript.txt`へ追記します。原作は`shiori.dll`という汎用名でも配布されているため、名前だけでmaeと判定させず、macOS用指定を使ってください。

```text
shiori.macos,libmae.dylib
```

`LICENSES/`も同梱してください。原作の辞書・画像・ゴーストはこのZIPには含みません。

## 対応範囲

- `mae_corpus.txt`のタグ、同名タグの条件順、`:case`、プログラム、論理行の継続、順次・ランダム・重複なしランダム選出
- Declaration → 保存変数の復元 → Initialize、および終了時のFinalize
- 32ビット整数・文字列・配列、演算と比較、if/while/begin、ユーザー関数・参照渡し
- `${変数}`、`%info`・`%event`・`%talk`・`%dtalk`・`%security`・`%teach`など、サーフィス名・イベント名の別名
- 日時・Reference・ユーザー名、時刻スロット、`mae_systemvar.txt`の宣言順によるシステム変数名変更
- 見切れ・重なりの開始／確定／解除、マウス移動による撫で、さくら側のサーフィス復帰、一部のReference付き派生タグ、基本的な自動トーク
- 品詞・ジャンル・部分文章の辞書変数、価値観による文章選択、基本的な気分・直近20タイトルの記憶、受信文の辞書語からのコミュニケート振り分け
- `sprint`・文字列比較・split/join、設定・Newsの各関数、macOS用SAORIのload/call/unload

辞書はUTF-8またはCP932、SHIORI/3.0電文はUTF-8またはShift_JISで扱います。CP932のASCIIバックスラッシュは文字列エスケープとして保持します。Windows用SAORI DLLは実行しません。長いループや深い再帰は上限でエラーになります。

0.1.0-r3では、未定義の`OnTranslate`・`OnBalloonClose`・リソース照会を発話へ置き換えません。表示終了をきっかけに「ネタ切れ」が繰り返される問題を修正し、`OnAITalk`を`Mae.Talk`へ接続します。該当タグを辞書で定義した場合はその処理を使います。ゴースト内の旧dylibが共通導入版より優先される場合は、そちらも更新してください。

## 保存の引き継ぎ

**Native版の保存がまだない初回起動時に、原作の`mae_variable.txt`・`mae_news.txt`を読み込みます。** 整数、文字列、配列要素、Newsのリビジョン・本文・登録時刻を引き継ぎ、その後は変数・設定・Newsを`mae-native-state.json`へ保存します。宣言から削除された変数や現在の配列範囲外の要素は読み飛ばします。壊れた保存レコードはロードエラーになり、新しい保存で上書きしません。

原作のファイルは書き換えません。Native版で進めた状態を原作DLLへ戻す双方向の保存互換はありません。更新前にゴーストをバックアップしてください。`mae.ini`は初期設定として読み込み、その後の変更はNative版の状態へ保存します。

原作NewsのFILETIMEは現地時刻として記録されるため、移行時のMacのタイムゾーンで復元します。別のタイムゾーンで作った保存には元のゾーン情報がなく、その時差は自動判定できません。

`UTATANE_GHOST_STATE_DIR`がある場合はその配下へ、`MAE_STATE_PATH`では指定された絶対パスへ状態を保存できます。

## 互換差と未対応

次は未対応または原作どおりとは保証していません。

- 猫どりふ、メール取得などBIFF固有処理。`OnBIFFComplete.n`など通常のイベントタグ選択は扱います。
- 起動時間・時報など全派生イベント、マウスホイールを含む撫での全判定、自動トークのランダムな追加待ち時間
- 応答中の単語が生む気分変化まで含めたコミュニケート再振り分け
- 短期記憶による品詞・ジャンルをまたぐ厳密な選出順、原作の乱数列
- SHIORI/2.x、原作への状態の書き戻し、任意のWindows依存機能

設定項目が欠けた`mae.ini`は原作と結果が変わる場合があります。Native版は原作が生成する初期値を補います。見切れ・重なりが同時に変わる場合など、複数候補間の厳密な優先順位は未確認です。

Newsが見つからない場合、Native版は仕様書に従って出力変数を空にします。原作DLLでは旧値が残るケースや、日時取得・経過時間取得で停止するケースを観測しました。原作の停止は再現せず、Native版の日時・経過時間・上書き・削除・失敗時の処理は合成テストで検証しています。

## 原作DLLとの比較（2026-10-30）

Wine 11.15で原作mae 3.1.6aを起動し、同じ合成辞書への32要求のValueを比較しました。30要求が一致しています。起動、順次選出、負の気分値、システム変数名変更、見切れ・重なり・撫で・サーフィス復帰・基本的なコミュニケート、原作の保存からの再起動、Newsの新旧リビジョン取得・削除を含みます。別途、原作のNews登録日時と移行後の日時、引用符・コンマ・バックスラッシュ・改行を含む保存文字列、および元ファイルが変わらないことを確認しています。

残る2要求は`sprint`の演算式・配列要素を引数に使うケースで、今回の辞書では原作が`0`、Native版が`14:3`を返しました。別の単純な辞書では配列要素を介した呼び出しが原作でも`14:3`になっており、発生条件は確定していません。この差は残しています。

配布ゴーストの一時コピーによる読み込み・起動応答・終了も確認しています。実画面、全イベント、すべての辞書での原作との一致を確認したものではありません。
