# 真絵（mae）

真絵（mae）の公開仕様を元にした、macOS用SHIORIです。バージョン0.1.0の部分互換版なので、利用前に下の対応範囲を確認してください。

## Utataneで使う

1. Utataneのメニューバーで「モジュール」→「モジュールカタログ…」を開きます。
2. このモジュールを選び、ダウンロードします。
3. 導入後は「機能」→「復旧操作」→「現在のゴーストを再読み込み」で、ゴーストを読み込み直します。

ゴーストにmacOS用のSHIORIが同梱されている場合は、そちらが優先されます。更新した版が使われているかは、「SHIORI読み込み診断」で確認できます。

## 手動で配置する・ゴーストへ同梱する

[公開仕様書](https://efasus.sakura.ne.jp/shiori_mae.html)から作った独立実装です。原作DLLの移植ではなく、バージョン0.1.0の部分互換版です。

ZIP内の`mae/lib/libmae.dylib`をゴーストの`ghost/master/`へ置き、`descript.txt`へ追記します。原作は`shiori.dll`という汎用名でも配布されているため、名前だけでmaeと判定させず、macOS用指定を使ってください。

```text
shiori.macos,libmae.dylib
```

`LICENSES/`も同梱してください。原作の辞書・画像・ゴーストはこのZIPには含みません。

## 互換範囲

真絵3.1.6aの辞書で、基本の会話・イベント・macOS用SAORIに対応します。初回に原作の変数とNewsを取り込み、以後はNative版の保存を使います。猫どりふやメール取得などは対象外です。
