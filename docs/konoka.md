# 此栞（Konoka）

此栞の公開技術メモと、回収できたカスタム版DLLの動作を元にしたmacOS用SHIORIです。0.2.0-r1は部分互換の試験版です。

## Utataneで使う

1. 「モジュール」→「モジュールカタログ…」で此栞を導入します。
2. 「機能」→「復旧操作」→「現在のゴーストを再読み込み」で読み込み直します。
3. 「SHIORI読み込み診断」で、此栞のNative版が選ばれたことを確認します。

配布カタログへの公開後に選択できます。手動で試す場合は、ZIPの`konoka/lib/libkonoka.dylib`をゴーストの`ghost/master/`へ置き、`descript.txt`に次を追加します。`LICENSES/`も同梱してください。

```text
shiori.macos,libkonoka.dylib
```

設定は`konoka.ini`、Windows用DLLと同名の`.ini`、`ks_cfg.txt`の順で探します。設定で`ai.txt`を指定していて実体が`ai.xdc`または`ai.xdi`だけの場合も読み込めます。辞書はUTF-8またはCP932です。

## 対応範囲

- `@イベント`・`\ev`、条件式、イベントの転送、通常トーク、基本的なコミュニケート
- 単語辞書、マクロ、リソース、Reference・日時・名前の展開
- 整数・文字列の演算、代入、両枝を評価する三項演算、`%変数`の事前展開と`$変数`の直接参照
- 文字列・リスト操作、`_isval`・`_get`・`_wordtype`、重複を除く単語登録、`_save`・`_load`
- `OnTeach`の単語・ヒント履歴、311・312応答、`values.dat`の初回取り込み
- XDC・XDI暗号化辞書の読み込み。開発用の`KonokaCipher.encode`・`decode`で相互変換もできます。

接続用の電文はSHIORI/3.0のUTF-8・Shift_JISです。原作のSHIORI/2.x用イベント辞書を、この入口から利用します。再帰・式・辞書サイズには上限があります。

## XDC・XDIの変換

ZIP内の`bin/konoka-dictionary`をターミナルから使えます。

```sh
/path/to/konoka/bin/konoka-dictionary encode ai.txt ai.xdc
/path/to/konoka/bin/konoka-dictionary decode ai.xdc restored.txt
```

暗号化時は出力、復号時は入力の拡張子が`.xdc`ならXDC、それ以外はXDIを使います。`--format xdi`または`--format xdc`を末尾へ付けて指定することもできます。設定で平文を指定していてファイルがない場合、XDC、XDIの順で探します。

出力先には新しいファイル名を指定してください。文字コードは入力のまま、復号後の改行はCRLFになります。原作DLLでも読む辞書はCP932で用意します。`ai.txt,e`のように設定すると、読み込み時に同名のXDCを生成・更新します。平文を編集して動作確認するたびに暗号化辞書も更新されます。

## 保存

`_save`と登録単語は`konoka-state.json`へ保存します。通常の代入変数は起動中の状態です。`UTATANE_GHOST_STATE_DIR`がある場合はその配下、`KONOKA_STATE_PATH`では指定した絶対パスを使います。Native側の保存がまだない初回には、原作の`values.dat`を読み込みます。元ファイルは取り込み元として保持します。試す前にゴーストをバックアップしてください。

## 互換差と確認範囲

[技術メモの保存版](https://web.archive.org/web/20040214165534/http://thor.prohosting.com/~kayono/technote.html)を参照しています。標準版0.44のソースは回収できておらず、最初の比較に使ったDLLは「さよこ＆トロロ」に同梱されたカスタム版です。この版は技術メモの`$変数`を解釈せず、版による差があります。

2026-11-08にWine上の原作DLLで、合成辞書の19要求（日本語・演算・イベント転送・単語展開・保存と復元・文字列操作など）がNative版と一致しました。単項の負数で原作DLLが応答を止めるケースは比較対象から分け、Native版のテストで確認しています。XDIは原作生成→Native復号、Native生成→原作実行の両方向を確認しています。配布ゴーストのXDI辞書3個について、Native版での読み込みと起動・毎秒・クリックなど5要求の処理も確認しました。実画面での動作と全イベントの一致は今後の検証範囲です。

チェイン会話、DTX形式、全組み込み変数・関数、コミュニケートの厳密な候補選択、原作の乱数列、原作へ戻す双方向の保存互換は今後の対応範囲です。標準DLLと技術メモからはSAORIの呼び出し仕様を確認できておらず、接続構文は調査中です。対応する辞書の範囲を増やしながら調整する版として使ってください。

2026-11-09には、作者がリンクしていた「がおちゃん」の保存NARから標準DLLを回収しました。31〜4,127 bytesの合成辞書10個で、標準DLLが生成したXDCとNative側の暗号化結果が完全一致しました。Native復号後の一致と、Native生成XDCの原作DLLでの実行も確認しています。XDIとXDCは別の方式として扱います。

## TeachBox

`OnTeach`のReference0が覚える単語、Reference1以降が最大16個のヒント履歴です。辞書では`%word`、`%hint0`〜`%hint15`、`%lasthint`、`%lastnum`を参照します。`\[shortage]`は311、`\[advice]`は312、`\[success]`は200応答になります。これらの制御指定は応答から取り除き、Teach本文は辞書の内容をそのまま返します。

2026-11-09に標準DLLで、保存の取り込み・組み込み関数・重複登録・TAB区切りリストの0始まりの添字・TEACHを合成辞書で照合しました。追加の10要求が一致し、自動生成したXDCのバイト列も一致しました。比較手順は`scripts/compare_konoka_standard_wine.py`にあります。入力された単語やヒントは表示・式の値として扱います。
