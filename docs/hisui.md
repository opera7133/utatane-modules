# 翡翠

翡翠の辞書を使うゴースト向けの、macOS用SHIORIです。phase00.20を元にした独立実装です。

## Utataneで使う

1. Utataneのメニューバーで「モジュール」→「モジュールカタログ…」を開きます。
2. このモジュールを選び、ダウンロードします。
3. 導入後は「機能」→「復旧操作」→「現在のゴーストを再読み込み」で、ゴーストを読み込み直します。

ゴーストにmacOS用のSHIORIが同梱されている場合は、そちらが優先されます。更新した版が使われているかは、「SHIORI読み込み診断」で確認できます。

## 手動で配置する・ゴーストへ同梱する

ZIP内の`hisui/lib/libhisui.dylib`を`ghost/master/`に置きます。Utataneでは既存の`descript.txt`の指定をそのまま使えます。

```text
shiori,hisui.dll
```

他のベースウェアで必要なら`shiori.macos,libhisui.dylib`を追加してください。

## 互換範囲

翡翠 phase00.20の辞書で、基本の会話・クリック反応・変数保存に対応します。感情値の自動学習は対象外です。

再配布時はZIPの`LICENSES/`も含めてください。
